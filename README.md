# SwordDolls

Физическая игра с управлением мечом.

## Скачать игру

[Готовая версия для Windows](https://github.com/Ki33s/SwordDolls/releases/latest). Распакуйте архив целиком и запустите **SwordDolls.exe**. Unity для запуска не нужен.

## Управление

WASD/стрелки или левый стик геймпада двигают меч. В меню A/D либо горизонтальная ось выбирает, W/вверх подтверждает после отпускания оси. Мышь: наведение и клик. Экранный стик появляется только на телефоне.
